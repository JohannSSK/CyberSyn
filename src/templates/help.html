Quick start

Γρήγορη εκκίνηση

  1. Create an administrator account on the sign-in page.
  2. Sign in as administrator, then add team members from the sign-in page.
  3. Open Settings, enter an API key, choose the checks you want, then press Apply and enter your admin password to save.
  4. Sign in as a team member and start chatting. A blocked prompt shows a card. An administrator can approve sending it anyway.
  5. Open Team to see each member's prompt counts, blocks and block reasons.
  1. Δημιουργήστε λογαριασμό διαχειριστή από τη σελίδα σύνδεσης.
  2. Συνδεθείτε ως διαχειριστής και προσθέστε μέλη ομάδας από τη σελίδα σύνδεσης.
  3. Ανοίξτε τις Ρυθμίσεις, εισάγετε ένα κλειδί API, επιλέξτε τους ελέγχους που θέλετε και πατήστε Εφαρμογή. Για αποθήκευση, εισάγετε τον κωδικό διαχειριστή σας.
  4. Συνδεθείτε ως μέλος ομάδας και ξεκινήστε τη συνομιλία. Ένα αποκλεισμένο prompt εμφανίζεται ως κάρτα. Ο διαχειριστής μπορεί να εγκρίνει την αποστολή του παρόλα αυτά.
  5. Ανοίξτε την Ομάδα για να δείτε τον αριθμό των prompts, τους αποκλεισμούς και τις αιτίες κάθε μέλους.

Privacy policy

Πολιτική απορρήτου

  • The authors do not run a server that collects your data. CyberSyn runs on the computer where you start it.
  • Usernames, passwords, prompts, replies, API keys and settings are stored in the local files listed under Where everything is stored. They are not sent to the authors.
  • Prompts are sent to the AI provider whose API key you save. That provider's privacy policy applies to those requests.
  • Passwords are stored as hashes. API keys are stored encrypted, not hashed, because the app needs the original key to call the provider.
  • The page loads the Inter and Instrument Serif fonts from Google Fonts. Google receives your IP address and browser details when the fonts load.
  • Removing an administrator deletes that admin's team members, settings and chat history from the local database.
  • For questions or requests, open an issue on the GitHub repository.
  • Οι δημιουργοί δεν διατηρούν διακομιστή που συλλέγει τα δεδομένα σας. Το CyberSyn εκτελείται στον υπολογιστή όπου το ξεκινάτε.
  • Τα ονόματα χρηστών, οι κωδικοί, τα prompts, οι απαντήσεις, τα κλειδιά API και οι ρυθμίσεις αποθηκεύονται στα τοπικά αρχεία της ενότητας Πού αποθηκεύονται τα δεδομένα. Δεν αποστέλλονται στους δημιουργούς.
  • Τα prompts αποστέλλονται στον πάροχο AI του οποίου αποθηκεύετε το κλειδί API. Για αυτά τα αιτήματα ισχύει η πολιτική απορρήτου του παρόχου.
  • Οι κωδικοί αποθηκεύονται ως hash. Τα κλειδιά API αποθηκεύονται κρυπτογραφημένα και όχι ως hash, επειδή η εφαρμογή χρειάζεται το αρχικό κλειδί για να καλέσει τον πάροχο.
  • Η σελίδα φορτώνει τις γραμματοσειρές Inter και Instrument Serif από το Google Fonts. Η Google λαμβάνει τη διεύθυνση IP και στοιχεία του προγράμματος περιήγησης όταν φορτώνουν οι γραμματοσειρές.
  • Η διαγραφή ενός διαχειριστή διαγράφει από την τοπική βάση δεδομένων τα μέλη ομάδας, τις ρυθμίσεις και το ιστορικό συνομιλιών του.
  • Για ερωτήσεις ή αιτήματα, ανοίξτε ένα issue στο αποθετήριο GitHub.

Cookies

  • CyberSyn does not set cookies for tracking, advertising or analytics.
  • Administrator sign-in is remembered with a token in your browser's localStorage, under the key cybersyn_admin_token. It is not a cookie. It expires after 7 days.
  • Pressing Switch administrator removes the token. Clearing the site data in your browser removes it too.
  • Το CyberSyn δεν ορίζει cookies για παρακολούθηση, διαφήμιση ή αναλυτικά στοιχεία.
  • Η σύνδεση του διαχειριστή θυμάται με ένα token στο localStorage του προγράμματος περιήγησης, με κλειδί cybersyn_admin_token. Δεν είναι cookie. Λήγει μετά από 7 ημέρες.
  • Με το πάτημα του Αλλαγή διαχειριστή αφαιρείται το token. Το ίδιο συμβαίνει και όταν διαγράφετε τα δεδομένα ιστότοπου στο πρόγραμμα περιήγησης.

Where everything is stored

Πού αποθηκεύονται τα δεδομένα

  • backend/app.db: the SQLite database. Tables: ADMINS (admin accounts, hashed passwords), EMPLOYEES (team members, hashed passwords, chat history in CHAT_LOGS), SETTINGS (checks, model and encrypted API key), ADMIN_SESSIONS (hashed admin tokens and expiry), BLOCK_LOG (stage and reason of each block).
  • backend/secret.key: the key that decrypts saved API keys. It is set to read-only for you (chmod 600). If the environment variable CYBERSYN_KEY is set, the app uses that instead. Losing this key makes saved API keys unreadable.
  • includes/constants.json: app constants, in the project root.
  • src/: the Flask app, templates and static files.
  • Browser localStorage: the administrator token only. Team member sessions are never kept, so a refresh signs them out.
  • backend/app.db: η βάση δεδομένων SQLite. Πίνακες: ADMINS (λογαριασμοί διαχειριστών, κωδικοί ως hash), EMPLOYEES (μέλη ομάδας, κωδικοί ως hash, ιστορικό συνομιλιών στο CHAT_LOGS), SETTINGS (έλεγχοι, μοντέλο και κρυπτογραφημένο κλειδί API), ADMIN_SESSIONS (hash των tokens διαχειριστή και λήξη), BLOCK_LOG (στάδιο και αιτία κάθε αποκλεισμού).
  • backend/secret.key: το κλειδί που αποκρυπτογραφεί τα αποθηκευμένα κλειδιά API. Έχει δικαίωμα μόνο ανάγνωσης για εσάς (chmod 600). Αν έχει οριστεί η μεταβλητή περιβάλλοντος CYBERSYN_KEY, η εφαρμογή χρησιμοποιεί αυτήν. Αν χαθεί αυτό το κλειδί, τα αποθηκευμένα κλειδιά API δεν θα είναι αναγνώσιμα.
  • includes/constants.json: σταθερές της εφαρμογής, στον ριζικό φάκελο του έργου.
  • src/: η εφαρμογή Flask, τα templates και τα στατικά αρχεία.
  • localStorage του προγράμματος περιήγησης: μόνο το token διαχειριστή. Οι συνεδρίες μελών ομάδας δεν διατηρούνται ποτέ, οπότε η ανανέωση της σελίδας τα αποσυνδέει.
