Quick start
  1. 1 Create an administrator account from the sign-in screen.
  2. 2 Sign in as administrator, then add your team members.
  3. 3 Open Settings, paste an API key, choose your model and which checks run.
  4. 4 Sign in as a team member and start chatting. A blocked prompt shows a card naming the line and the reason.
  5. 5 Open Statistics to see who was blocked, why, and when.
The three checks

1 · Personal & Greek IDs

AFM validated by checksum, AMKA, Greek phone numbers, email addresses, API keys, company names and person names in both English and Greek.

2 · Confidential context

Contracts and NDAs, internal financials, HR and payroll records, credentials and connection strings, and source code.

3 · Prompt injection

Instructions trying to override the model's rules, jailbreaks, and payloads hidden inside code comments.

What never leaves this machine
Your prompts Screened locally before sending
Your API key Stored encrypted, only ever shown masked
Blocked messages Never transmitted to any provider
Inspection itself No third-party classifier is consulted
When a check cannot run

The gate fails closed: if a scanner errors, times out or returns no verdict, the prompt is refused rather than forwarded. You will see an error naming the check instead of a reply.
