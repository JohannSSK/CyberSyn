Guide

How CyberSyn works

What runs before a message reaches the AI, what stays on this computer, and what administrators can and cannot see.

The short version

CyberSyn applies your workspace policy on the gateway before it sends a message to the configured AI provider.

1
Write your message as usual

Draft an email, paste code, summarise a note or ask a question in Chat. Nothing leaves this computer while you type.

2
Enabled rules inspect it locally

Local checks cover personal data, confidential context, prompt injection and source code.

3
The policy decides what is sent

A rule can allow, pause for review, redact or block the message. If an enabled check fails, nothing is sent.

The four screening rules
Personal & Greek IDs

Catches names, email addresses, phone numbers, payment cards, IBANs and Greek national numbers such as AFM and AMKA before they reach an external model.

Confidential context

Reads the surrounding sentence to spot confidential plans, internal credentials or client information that does not follow a fixed number format.

Prompt injection

Detects hidden instructions trying to override how the model behaves — common in pasted web pages, forwarded emails and shared documents.

Proprietary source code

Applies a separate rule to recognized source code. CyberSyn does not determine who owns the code.

Policy actions
Allow

Skip that rule; the other enabled rules still apply.

Warn

Pause and show the matches. You can edit the prompt or send anyway. Confirmation runs the current checks again.

Redact & send

Replace detected values with placeholders before sending and saving. Optional local restoration swaps matching placeholders back for this reply only. History keeps the unrestored answer.

Block

Keep the message local. Edit it or ask for one-time administrator approval. Redaction rules still apply to an approved override.

Blocks take precedence over warnings, then redaction. Prompt injection cannot be set to Redact.

Shadow AI discovery

On Shadow AI, review the service inventory, choose approved, restricted or unapproved, and import synthetic CSV, proxy or DNS logs. Use the sample week and the client-data filter to see which teams accessed unapproved tools.

Log discovery never contacts the network. Only hostnames and event metadata are kept, not URL paths, queries or message content. This is an analysis of imported logs, not live network monitoring.

Signing in

Use the Team member tab to open your own conversations. Enter your administrator's username as the workspace name if there is more than one workspace.

Use the Administrator tab to go directly to Shadow AI, Statistics, Team and account management. Member sign-in ends the administrator session in that browser.

Privacy, visibility and deletion

CyberSyn runs on a computer managed by your organisation. Here is what is stored locally and who can read it:

Conversations and AI replies

Sent messages and replies are stored in the local database for your account. For redacted exchanges, only the sanitized prompt and unrestored reply are saved. Administrator screens do not load your conversations.

What administrators can see

Administrator pages show counts, rule categories and timestamps. Prompt previews are off by default. If enabled, only ordinary messages may leave a preview in the local audit log; blocked, warned, redacted and overridden text never does.

Deleting messages, chats and accounts

Deleting a message or a chat removes it from your conversation history straight away; append-only block records, activity log entries and message counters remain in the local database for auditing. Removing a member or administrator deletes their sign-in, active sessions and saved model/key settings immediately; historical audit entries remain in the database file until wiped on disk.

API keys, sessions and external requests

Provider API keys are encrypted before they are saved and shown masked everywhere on screen. Sessions use HttpOnly cookies stored as SHA-256 hashes on the server with server-side expiry and revocation. Typefaces are bundled locally (Instrument Serif, Noto Serif Display, Inter and JetBrains Mono under the SIL Open Font License 1.1) — CyberSyn makes outbound requests only to the AI provider configured for your seat.

Models and API keys

CyberSyn works with OpenAI, Anthropic Claude, Google Gemini, Mistral, Cohere, Groq, DeepSeek and xAI Grok. Automatic discovery uses recognized key prefixes only; select your provider explicitly for unfamiliar formats. An administrator selects the model and saves the matching provider API key for each signed-in member on the Settings page.

Everyday shortcuts and tips
  • Press Enter to send a message and Shift + Enter to add a new line.
  • Use the search box at the top of Chat to filter the open conversation and search across other chats; press Esc to clear it.
  • When signed in as a member, administrator pages can be unlocked for 15 minutes. Use Lock now in the sidebar to end that access.
  • On Statistics, use Download CSV to export workspace totals and trends, or print either Statistics or Team cleanly to A4 — API keys and prompt excerpts are omitted on paper.
